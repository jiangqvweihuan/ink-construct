# InkConstruct 美术资源清单（Demo 版）

> 项目：InkConstruct ｜ 引擎：Godot 4.6（GL Compatibility）｜ 类型：2D 横版动作 Roguelike
> 参考作品：Skul: The Hero Slayer ｜ 画风：水墨
> 版本：v0.1 ｜ 用途：初步 Demo 立项素材需求

---

## 一、美术方向约定（采购/外包前必须先定）

水墨与像素风最大的区别是：**不能做像素图**。水墨依赖毛边、飞白、浓淡晕染，必须手绘或矢量绘制。

| 项 | 约定值 |
| --- | --- |
| 基准分辨率 | 1920×1080（16:9） |
| 像素密度 PPU | 64（1 世界单位 = 64px） |
| 玩家角色高度 | 约 128px |
| 普通敌人 | 96–160px |
| 精英 | 200–260px |
| Boss | 480–640px |
| 交付格式 | PNG-32 带透明通道，建议 2x 绘制后降采样 |
| 成套动画单位 | 提供 Spine / DragonBones 工程 + PNG 分件，不接受只给 GIF 或录屏 |
| 朝向 | 全部朝右，左向由引擎翻转 |

### 色板（全项目共用 6 色）

| 用途 | 色值 |
| --- | --- |
| 焦墨（轮廓/主体） | `#0D0D0D` |
| 浓墨（暗部） | `#1A1A1A` |
| 淡墨（灰面/远景） | `#6B6B6B` |
| 飞白（高光/受光） | `#C8C8C8` |
| 宣纸底 | `#F2EAD8` |
| 朱砂（印章/血量/危险） | `#A8322A` |

辅助色：石青 `#2E5C6E`、赭石 `#8C5A3C`。

### 硬性要求

- 边缘必须有毛边与墨渗，**禁止 1px 硬描边**（水墨素材最常见的验收失败点）
- 先出黑白剪影做可读性测试，剪影不清晰的动作直接退回
- 切图之间留 ≥4px 透明边距，防止缩放时拉边

## 二、动画方案（先定这个，它决定素材量）

| 方案 | 素材量 | 水墨适配度 |
| --- | --- | --- |
| **分件骨骼（Spine / DragonBones）** | 小 | 推荐，笔触可绑在骨架上，飘动自然 |
| 逐帧手绘 | 大 3–5 倍 | 质量最高，但 Demo 阶段成本不可控 |

以下清单按**分件骨骼**估算。若改用逐帧，所有动画帧数请 ×4–6。

## 三、P0 清单：跑通 Demo 的最小闭环

### 3.1 玩家角色

基础形态（1 套，水墨书生 / 剑客剪影风）

| 动画 | 帧数 | 备注 |
| --- | --- | --- |
| idle | 6 | 衣摆、袖口飘动循环 |
| run | 8 | |
| jump / fall / land | 3 / 3 / 3 | 可合并为一套 |
| dash | 4 | 另需 2 张残影剪影 |
| 普攻 1 / 2 / 3 | 5 / 5 / 6 | 三连击，第三段终结重击 |
| hurt | 2 | |
| death | 6 | 化墨消散 |
| 拾取 / 交互 | 4 | 可复用 |

分件约 12–16 个（头、躯干、双臂、双腿、配剑、飘带）。

骷髅形态 ×2（Skul 核心机制，Demo 必须体现「换头」）

| 形态 | 需要动画 |
| --- | --- |
| 剑客头 | idle 4 + 攻击 5 + 技能 6 |
| 弓手头 | idle 4 + 攻击 5 + 技能 6 |

省成本方案：**移动动画共用基础形态**，每个骷髅头只做「待机 + 普攻 + 技能 + 特写头像」。

另需：2 张骷髅切换特写、1 张技能起手。

### 3.2 敌人（4 普通 + 1 精英 + 1 Boss）

| 单位 | 动画 | 尺寸 |
| --- | --- | --- |
| 墨傀儡（近战小兵） | idle 4 / walk 6 / attack 5 / hurt 2 / death 5 | 110px |
| 竹节弓手（远程） | idle 4 / aim 3 / shoot 4 / hurt 2 / death 5 | 120px |
| 墨鸦（飞行俯冲） | fly 6 / dive 4 / hurt 2 / death 5 | 90px |
| 石狮（冲锋重甲） | idle 4 / charge 6 / stagger 3 / death 6 | 160px |
| 精英 · 墨将 | idle 6 / 三套招式各 6 / 破防 4 / death 8 | 240px |
| Boss · 水墨巨像或墨龙 | 入场 10 / idle 6 / 招式 4 套各 8 / 转阶段 12 / death 12 | 560px |

Boss 是单项最大工程量，**建议先做 1 阶段 3 招式简化版**。

### 3.3 场景（1 个生态：残卷山谷 / 废弃书院）

| 类别 | 数量 | 说明 |
| --- | --- | --- |
| 地面 tileset | 12–16 格 | 64×64 网格，含平地、斜坡、边角、破损、悬空 |
| 单向平台 | 3 种 | 短 / 中 / 长 |
| 视差背景 | 4 层 | 远山雾、竹林、书院檐影、近景飘落墨点 |
| 装饰 props | 12–15 个 | 灯笼、残碑、卷轴堆、香炉、破旗、纸人、枯竹 |
| 可交互物 | 6 类 | 传送门、宝箱、商店台、治疗墨池、存档点、可破坏陶罐 |
| 危险物 | 3 种 | 尖刺、地火、落石 |

### 3.4 UI（约 45 个切图）

| 分组 | 内容 |
| --- | --- |
| 标题 | 毛笔字 Logo + 朱砂印章 + 主菜单背景 |
| 按钮 | 普通 / 悬停 / 按下 三态 × 2 尺寸 |
| 战斗 HUD | HP 条（框/填充/低血闪烁）、护盾条、技能槽 ×4（空/就绪/冷却遮罩）、骷髅槽 ×2、金币与墨骨计数 |
| 地图 | 小地图框、全图界面、房间节点图标 ×6（战斗/精英/商店/宝箱/Boss/未知） |
| 道具 | 道具图标 12 个、状态图标 8 个（燃烧/中毒/减速/护盾等） |
| 其他 | 对话框、提示气泡、伤害数字 ×3（普通/暴击/治疗）、暂停与结算面板底框 |

| --- | --- |
| 刀光（轻 / 重 / 终结） | 3 |
| 命中墨爆（小 / 中 / 大） | 3 |
| 落地尘土、冲刺残影 | 2 |
| 死亡化墨消散 | 1 |
| 治疗、拾取高光 | 2 |
| Boss 预警墨圈 | 2 |

## 六、验收清单（拿到素材逐条核对）

1. 透明通道正常，无白边或黑边
2. 尺寸符合约定，玩家 128px 高
3. 角色朝右，脚底锚点在底部中心
4. 提供 Spine / DragonBones 工程文件，不只是 PNG
5. 无 1px 硬描边，边缘有毛边
6. 同一套动画帧率与时长一致
7. 命名符合 `类型_对象_动作_序号`（如 `char_player_run_00`）
8. 每张图留 4px 切图边距

**P0 素材总量估算**：角色 10 组动画 + 6 个敌人单位 + 1 套场景 + 45 个 UI 切图 + 25 个 VFX，切图文件约 **180–220 个**。

## 七、目录结构约定

素材按下表归位，`source_art/` 存放原始工程（Spine 工程、PSD、笔刷源文件），已放置 `.gdignore` 让 Godot 不导入原始工程。

```
ink-construct/
├── art/                        # 进入游戏的最终资源（res://art）
│   ├── characters/
│   │   ├── player/             # 玩家基础形态（分件 + Spine 工程导出的图集）
│   │   │   └── skulls/         # 骷髅形态：剑客头、弓手头
│   │   ├── enemies/            # 4 种普通敌人 + 精英墨将
│   │   └── bosses/             # Boss
│   ├── environment/
│   │   ├── tilesets/           # 64×64 地面 tileset
│   │   ├── background/         # 4 层视差背景
│   │   └── props/              # 装饰物、可交互物、危险物
│   ├── ui/
│   │   ├── hud/                # 血条、技能槽、骷髅槽、货币
│   │   ├── menus/              # 标题、主菜单、暂停、结算
│   │   └── icons/              # 道具图标、状态图标、地图节点图标
│   ├── vfx/                    # 刀光、墨爆、化墨消散、转场遮罩
│   └── fonts/                  # 标题书法体 + 正文宋体
├── audio/
│   ├── bgm/
│   └── sfx/
├── scenes/                     # 场景文件（.tscn）
│   ├── player/
│   ├── enemies/
│   ├── world/
│   └── ui/
├── scripts/                    # 脚本
│   ├── player/
│   ├── enemies/
│   ├── systems/
│   └── ui/
├── docs/                       # 本文档
└── source_art/                 # 原始工程（.gdignore，不进引擎）
```
